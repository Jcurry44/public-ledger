The method

Built exactly like every Public Ledger edition. Parsed from the Comptroller’s statewide school-district files — 7,014 account-level rows for this district, FY1995–FY2025 — joined on municipal code (never entity name), flows only, balance-sheet rows excluded. The 2013 schema change is resolved by column name per era and marked on every chart. The build is a gate, not a report: if any year goes missing or a total turns implausible, the generator halts and this page does not update.
