The method

How it was built

Built exactly like every Public Ledger edition. Parsed from the Comptroller’s statewide village files — 4,091 account-level rows for Middleport, 1995–2025 — joined on municipal code (never entity name), flows only, balance-sheet rows excluded. The 2013 schema change is resolved by column name per era and marked on every chart. The build is a gate, not a report: if any year goes missing or a total turns implausible, the generator halts and this page does not update.

✓ BUILD GATES PASS: 31 consecutive years · totals in bounds · schema mapping continuous

Self-reported AFR data: OSC desk-reviews these filings but does not audit them. Populations are the 2020 Census, via New York State’s official mirror (data.ny.gov sxhg-qquj, retrieved 2026-07-31). Figures as filed; no inflation adjustment.
